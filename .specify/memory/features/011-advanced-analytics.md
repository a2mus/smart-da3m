# Feature Brief: Advanced Analytics Dashboard (F6)

**Priority**: Must Have — Proof of Efficacy
**Status**: 🔲 Pending — no spec yet
**Dependencies**: 006-adaptive-diagnostic-engine, 007-remediation-pathways, 008-parent-dashboard
**Complexity**: L (data aggregation, visualizations, export)

## Description
Implements the advanced analytics dashboard for experts and platform administrators. Expert-level: Competency Heatmap (students × competencies matrix, color-coded Red/Yellow/Green), Auto-Grouping (one-click remediation groups based on shared error patterns), class progress charts toward curriculum objectives, and printable remediation cards. Platform-level: Gap Reduction Rate (% improvement pre/post remediation), Mastery Speed (avg time to overcome learning obstacles), Retention Rate (1-week follow-up performance), Effort vs. Results analysis, and Resilience Score. Filterable by student, class, school, grade, subject, competency, time period. Exportable reports (PDF, CSV).
