# Feature Brief: Parent Dashboard (F3)

**Priority**: Must Have — Critical for Adoption
**Status**: 🔲 Pending — no spec yet
**Dependencies**: 007-remediation-pathways (needs remediation data), 005-navigation-restructure
**Complexity**: M (data visualization, mobile-first, bilingual)

## Description
Delivers the mobile-first parent dashboard with simplified pedagogical reporting. Instead of raw scores, parents receive "smart messages" describing their child's strengths and gaps per competency (e.g., "Your child excels at oral expression but needs help with taa marbouta spelling"). Features: radar chart showing subject balance (Arabic/Math/French), clearly identified strengths and gaps, actionable daily recommendations (e.g., "5 minutes of mental arithmetic"), pedagogical alert notifications, post-session summaries, and weekly progress reports with visual trends. Available in Arabic RTL and French LTR.
