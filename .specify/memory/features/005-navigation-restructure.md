# Feature Brief: Navigation Restructure & Role-Based User Experience

**Priority**: Must Have — High
**Status**: 🔲 Planned — spec + plan exist, needs tasks + implementation
**Dependencies**: 004-mock-auth-state
**Complexity**: L (cross-cutting navigation, 3 role dashboards, landing page)

## Description
Restructures the entire site navigation architecture around role-based routing. Delivers: (1) a polished welcome landing page with platform value proposition, feature highlights, and CTA buttons (Sign Up / Sign In), (2) role-specific authentication paths (Parent/Expert via email+password, Student via pseudo+PIN), (3) dedicated dashboard interfaces for each role (Parent, Expert, Student) with appropriate content and navigation, and (4) automatic redirect for authenticated users. Unifies the existing mockup components into a coherent, navigable application flow.
