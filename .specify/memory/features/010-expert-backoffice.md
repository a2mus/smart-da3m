# Feature Brief: Expert Back-Office (F5)

**Priority**: Must Have — Content Foundation
**Status**: 🔲 Pending — no spec yet
**Dependencies**: 005-navigation-restructure
**Complexity**: L (full CRUD admin panel, content management)

## Description
Builds the pedagogical expert administration panel for content creation and management. CRUD operations for: Modules (matière → niveau → domaine → compétence hierarchy), Resources (micro-learning videos, interactive exercises, mind maps, stories), and Question banks with metadata (difficulty, target competency, misconception tags, estimated time). Content structured per Algerian school years (السنة 1-5). Features: content tagging (language, age band, remediation type), preview mode (simulate student experience), bulk import/export (CSV/JSON), and content versioning. The back-office is the foundation for all pedagogical content that powers features 006 and 007.
